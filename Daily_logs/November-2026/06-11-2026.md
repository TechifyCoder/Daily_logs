# 1. Combination Sum II

## Problem

Given an array `candidates` and a target value, find all unique combinations whose sum is equal to the target.

Rules:
- Each element can be used only once in a combination.
- The answer must not contain duplicate combinations.

## Example

**Input**
```text
candidates = [10, 1, 2, 7, 6, 1, 5]
target = 8
```

**Output**
```text
[
  [1, 1, 6],
  [1, 2, 5],
  [1, 7],
  [2, 6]
]
```

## Explanation

Each combination adds up to `8`:

- `[1, 1, 6]` → `1 + 1 + 6 = 8`
- `[1, 2, 5]` → `1 + 2 + 5 = 8`
- `[1, 7]` → `1 + 7 = 8`
- `[2, 6]` → `2 + 6 = 8`

An element cannot be reused in the same combination, and the same combination should not appear more than once.

## My Approach

I worked through the recursion/backtracking approach and focused on how to build combinations that reach the target.

The important parts of this problem are:
- Move to the next index after choosing an element, because an element can be used only once.
- Sort the array so equal values are next to each other.
- Skip equal values at the same recursion level to avoid duplicate combinations.

## Problem Faced

- I forgot to sort the array before applying the duplicate-handling logic.
- I did not handle duplicate elements correctly at first.
- I needed to pay more attention to the difference between using an element once and skipping duplicate choices.

# 2. Subsets I

## Problem

Given an array of distinct integers, return all possible subsets of the array, including the empty subset and the original array.

## Example

**Input**
```text
nums = [1, 2, 3]
```

**Output**
```text
[
  [],
  [1],
  [2],
  [1, 2],
  [3],
  [1, 3],
  [2, 3],
  [1, 2, 3]
]
```

## Explanation

For every element, there are two choices:

- **Pick:** Include the current element in the subset.
- **Not Pick:** Do not include the current element.

For an array of `3` distinct elements, the total number of subsets is `2^3 = 8`.

## My Approach

I first drew the recursion tree and identified the two choices for each element:

1. Pick / Include the current element.
2. Not Pick / Exclude the current element.

After understanding the tree, I identified the base case and then wrote the code.

I completed this problem independently without facing any major difficulty.
