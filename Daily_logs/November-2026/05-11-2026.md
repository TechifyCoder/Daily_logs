# Generate Binary Strings Without Consecutive 1s

## 1. Problem Statement

Given an integer `n`, generate all possible binary strings of length `n` such that no two consecutive characters are `1`.

In other words, the string must not contain `"11"` anywhere.

## 2. Input

```text
n = 3
```

## 3. Expected Output

```text
000
001
010
100
101
```

## 4. Explanation

For `n = 3`, we need to generate all binary strings containing exactly 3 characters.

- `000` – Valid
- `001` – Valid
- `010` – Valid
- `100` – Valid
- `101` – Valid
- `011` – Invalid (contains consecutive 1s)
- `110` – Invalid (contains consecutive 1s)
- `111` – Invalid (contains consecutive 1s)

Therefore, only 5 valid binary strings are generated.

## 8. Recursive Approach

Use recursion and backtracking to generate valid binary strings.

At every position, we have two possible choices:

**Choice 1: Add '0'**
- Adding `0` is always valid.
- Append `0` to the current string.
- Make a recursive call.
- Remove the appended character using `pop_back()`.

**Choice 2: Add '1'**
- Add `1` only when the string is empty or its last character is `0`.
- This prevents consecutive `1`s.
- Make a recursive call.
- Remove the appended character after returning.

**Base Case:**

When `s.size() == n`, store the generated string in the answer vector and return.

## 9. C++ Solution

```cpp
class Solution {
public:
    void solve(int n, string &s, vector<string> &ans) {

        if(s.size() == n) {
            ans.push_back(s);
            return;
        }

        // Add 0
        s.push_back('0');
        solve(n, s, ans);
        s.pop_back();

        // Add 1 only when valid
        if(s.empty() || s.back() == '0') {
            s.push_back('1');
            solve(n, s, ans);
            s.pop_back();
        }
    }

    vector<string> generateBinaryStrings(int n) {
        vector<string> ans;
        string s = "";

        solve(n, s, ans);

        return ans;
    }
};
```

## 10. Key Learnings

- `push_back()` adds a character at the end of a string.
- `pop_back()` removes the last character.
- Every recursive call explores a valid choice.
- Backtracking follows Choose → Explore → Undo.
- Checking the last character is sufficient to prevent consecutive `1`s.
- Recursion does not always follow the Pick / Not Pick pattern.

## 11. Complexity Analysis

Let `F(k)` represent the Fibonacci sequence.

- **Time Complexity:** O(n × F(n + 2))
- **Auxiliary Space:** O(n) for recursion stack.
- **Output Space:** O(n × F(n + 2)) for storing all valid strings.
