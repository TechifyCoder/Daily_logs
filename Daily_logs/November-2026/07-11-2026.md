# Subsets II

## 1. Problem Statement

Given an integer array `nums` that may contain duplicate elements, return all possible subsets (the power set).

The answer must not contain duplicate subsets.

## 2. Input

```text
nums = [1, 2, 2]
```

## 3. Expected Output

```text
[
  [],
  [1],
  [1, 2],
  [1, 2, 2],
  [2],
  [2, 2]
]
```

## 4. Explanation

The input contains duplicate values (`2` appears twice). The task is to generate every possible subset, but each unique subset should appear only once in the answer.

For example, `[2]` should not be added more than once.

## 5. My Approach

I had already solved **Subsets I**, so I was familiar with the Pick / Not Pick recursion pattern.

I used that understanding to approach Subsets II:
- Pick the current element and move to the next index.
- For the Not Pick choice, skip duplicate values at the same recursion level.
- Sort the array first so that equal values are next to each other. This makes duplicate skipping possible.

## 9.Solution

```cpp
class Solution {
public:
    void solve(int i, vector<int>& nums, vector<vector<int>>& ans,
               vector<int> &ds) {
        if (i >= nums.size()) {
            ans.push_back(ds);
            return;
        }

        ds.push_back(nums[i]);
        solve(i + 1, nums, ans, ds);
        ds.pop_back();
        while (i + 1 < nums.size() && nums[i] == nums[i + 1]) {
            i++;
        }
        solve(i + 1, nums, ans, ds);
    }
    vector<vector<int>> subsetsWithDup(vector<int>& nums) {
        sort(nums.begin(),nums.end());
        vector<vector<int>> ans;
        vector<int> ds;

        solve(0, nums, ans, ds);

        return ans;
    }
};
```
